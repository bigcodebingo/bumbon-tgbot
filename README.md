# Бумбон

Telegram-бот на Python 3.12+ и aiogram 3.

## Запуск в PowerShell

```powershell
Set-Location C:\Users\gach1van\Desktop\bumbon-tgbot
uv sync
uv run python -m bumbon
```

В `.env` должен быть указан `BOT_TOKEN` (образец — `.env.example`).
Не запускайте одновременно старую и новую версии с одним токеном.

## Команды

- `/start` — приветствие.
- `/help` — описание доступных команд.
- `/all` — упоминание администраторов текущей группы, кроме
  ботов и пользователя, вызвавшего команду. Доступна любому участнику.

При запуске команды также регистрируются в меню Telegram.

## Как работает /all

При каждом вызове бот запрашивает актуальный список администраторов
через `get_chat_administrators()`, исключает ботов и автора команды,
затем отправляет упоминания. Предварительные сообщения участников
не нужны. Реестр участников и база данных не используются.

Обычные участники без прав администратора не упоминаются. Если все
участники беседы — администраторы, команда позовёт всех остальных людей.

Упоминания используют Telegram ID и работают без username.
Большие списки разбиваются на несколько сообщений. При отправке
команды от имени канала или анонимного администратора бот просит
вызвать её от личного имени, чтобы можно было исключить автора.

## Проверка в Telegram

1. Запустите бота и проверьте `/start` и `/help` в личном чате.
2. Добавьте его в тестовую группу и назначьте администратором.
3. Назначьте другого участника администратором и вызовите `/all` от своего имени.
4. Проверьте упоминание этого администратора и отсутствие автора команды и ботов.
5. Снимите с участника права администратора: следующий `/all` не должен его упоминать.
